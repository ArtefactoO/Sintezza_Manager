# Changelog

## 0.2.1

- Put the All, Enabled, and Disabled filters in that order.
- Keep group arrows usable in search results and restore the ordinary group layout when search is cleared.

## 0.2.0

- Show each addon's declared icon beside its name in the AddOns list.
- Open the manager from the built-in AddOns button in the game menu.
- Mark out-of-date addons and let players stage the game's load out-of-date addons setting alongside individual addon changes.

## 0.1.1

- Show all addons by default and update checkboxes immediately when changes are staged.

## 0.1.0

- Add a searchable addon list with modules grouped under their parent addon and an initial Disabled filter.
- Save account-wide addon sets and load them manually for any character. Review the draft before applying and reloading.
- Open Sintezza Addons Manager from the game menu, AddOns settings, or the slash command. Show the installed version in the header and use the shared Sintezza Theme sidebar and checkbox styles when available.
- Add resizable windows, shared Theme window preferences, a denser list with clear on and off states, and an original addon icon.
- Collapse nested groups, see module counts, stage group changes from the context menu, and rename or duplicate saved profiles.
- Show all modules in expanded groups when filtering by addon state and show the disabled count out of the group total.
- Separate addon management from saved profile details, keep Load and Save visible in the compact toolbar, and show applied checkmarks alongside pending state transitions.
- Enlarge addon rows, checkboxes and disclosure arrows, and use Theme's shared row bands and hover treatment.
- Allow the window to be resized down to 480 UI pixels and adapt toolbar labels and dialogs to the narrow layout.
- Use the Sintezza Theme chevron for pending state changes, with an ASCII fallback for standalone mode.
- Put status filters below search and category selection, and show categories in the shared Theme picker.
